Commands added to ISOLDE by the ChimeraX-ISOLDE-DNA_RESTRAINTS bundle

isolde restrain b-dna residues [ springConstant k ] [ torsions true | false ] [ distances true | false ] [ reset true | false ]

Restrain a DNA duplex to B-form. residues must contain only DA/DC/DG/DT residues from exactly two chains with the same number of residues; the two chains are paired first-to-last in antiparallel fashion (lowest-numbered residue of the alphabetically first chain with the highest-numbered residue of the second chain), so the selection must cover whole duplex segments.

  • torsions (default true): adaptive dihedral restraints to B-DNA targets for alpha, beta, gamma, delta, epsilon, zeta, the sugar torsions v0–v4 and the glycosidic torsions chi1/chi2.
  • distances (default true): adaptive distance restraints for the P–P minor- and major-groove widths, for atom pairs across each base pair, and for atom pairs within each nucleotide.
  • springConstant (default 5000 kJ/mol/rad²): torsion restraint strength.
  • reset (default false): re-set the targets of existing torsion restraints (otherwise only new restraints get targets; all of them get the spring constant).

Terminal residues lack some atoms/dihedrals; the corresponding restraints are simply not created.

isolde adjust b-dna residues [ backbone true | false ] [ sidechains true | false ] [ angleRange degrees ] [ alpha a ] [ springConstant k ]

Change the width (angleRange), the force falloff (alpha) and/or the strength of existing B-DNA torsion restraints. backbone covers alpha–zeta and v0–v4, sidechains covers chi1/chi2. Only existing restraints are changed.

isolde release b-dna residues [ backbone true | false ] [ sidechains true | false ]

Switch off B-DNA torsion restraints. Distance restraints created by isolde restrain b-dna are not affected.

isolde stepgap [ next | prev ] [ model model ] [ polymericOnly true | false ] [ select true | false ] [ viewDistance d ] [ interpolateFrames n ]

Move ISOLDE's residue stepper (see isolde stepto) to the next (default) or previous gap: the first residue after a numbering gap, or at a change of chain the last residue of the old chain and the first of the new one. If there is no further gap in that direction nothing happens.
